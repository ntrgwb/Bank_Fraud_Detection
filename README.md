## Dataset

This project uses the **Bank Account Fraud (BAF) Dataset – NeurIPS 2022**.

- Source: Kaggle
- Dataset size: 1,000,000 records
- Target variable: `fraud_bool`
- Fraud rate: approximately 1.1%
- Number of original features: 31

Dataset:
https://www.kaggle.com/datasets/sgpjesus/bank-account-fraud-dataset-neurips-2022/discussion?sort=hotness
